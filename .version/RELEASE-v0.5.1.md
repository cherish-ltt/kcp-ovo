# v0.5.1

本版本修复下游全局分配器冲突：移除 mimalloc 依赖及库内全局分配器声明，
由最终应用决定内存分配策略。

## 主要变化

- 修复 #36：应用自行声明 System、mimalloc 等全局分配器时，kcp-ovo 不再与其冲突；默认 Stream feature 和关闭默认 feature 均适用。
- 增加下游显式选择 System 分配器的编译回归，Rust CI 与发布校验同时覆盖全 feature 和无默认 feature 配置。
- 更新 README、库文档及故障排查说明，不再建议修改库源码来禁用分配器。
- 纳入 v0.5.0 后补充的黑盒覆盖：最大分片消息与黑洞恢复、输出错误恢复、Stream 背压隔离与取消恢复，以及 1/8/20 客户端回环负载观测。

## 升级注意

- 公共 API、feature 名称和协议线格式不变；无需修改现有 KCP 调用。
- 原先没有声明分配器的应用不再隐式使用 mimalloc，而是使用 Rust 默认分配器。仍需 mimalloc 的应用应自行添加依赖，并在最终程序中声明一次 `#[global_allocator]`；库不提供分配器 feature。
- 分配器变化可能影响吞吐、延迟和内存占用，需按应用自身负载测量；本版本不宣称性能提升，回环测试也不代表生产性能。
